# Third-party references and acknowledgements

The following public projects were reviewed as design and research references. Their code, prompt text, and skill files are **not bundled or copied** in this repository; ResearchForge's skills and utilities were written independently. Names and links are provided for provenance and to acknowledge useful ideas.

- **Adkid-Zephyr/anti-defensive-writing-Skill** — MIT-licensed bilingual academic-writing skill. Its focus on removing defensive prose informed the scope of `anti-defensive-writing`. ResearchForge changes the approach materially: clarity and confident argument are allowed, but material negative results, relevant limitations, and inconvenient comparisons must remain. Upstream: https://github.com/Adkid-Zephyr/anti-defensive-writing-Skill
- **deanpeters/Product-Manager-Skills** — reference for a flat, independently usable skill-folder structure, plain-language skill discovery, and practical entry points. Upstream: https://github.com/deanpeters/Product-Manager-Skills
- **KalarisLabs/research-agent-skills** — reference for broad research-lifecycle coverage, including literature, experimental design, analysis, citation checks, and peer review. Upstream: https://github.com/KalarisLabs/research-agent-skills
- **O0000-code/awesome-academic-skills** — reference index for comparing academic-research skill categories and checking the licensing status of external projects. Upstream: https://github.com/O0000-code/awesome-academic-skills
- **Angobaba/agentic-research-assistant** — reference for supervised research workflows and explicit checkpoints. Upstream: https://github.com/Angobaba/agentic-research-assistant
- **Agent Skills format** — portable folder format built around a `SKILL.md` file with YAML frontmatter and optional resources. Reference: https://github.com/microsoft/skills and https://agentskills.io/

No affiliation, sponsorship, or endorsement by these projects is implied. Each upstream repository retains its own license and ownership. If future contributions incorporate upstream code or text, the relevant license and copyright notices must be added before distribution.
