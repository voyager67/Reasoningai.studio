# Rebuttal And Response

## Purpose

Make reviewer responses respectful, specific, and auditable without promising experiments that were not run or conceding claims that are supported.

## Input

Bring any material already available: reviewer comments, manuscript version, available analyses, response word limit, venue rules, and changes already made. If an essential item is absent, state the gap and proceed with a clearly labelled provisional plan rather than repeatedly asking for information that is already present.

## Workflow

1. Split each reviewer comment into atomic requests or claims; preserve the original comment and numbering.
2. Classify each item: clarify text, add citation, correct error, provide existing evidence, run new analysis, explain a limitation, or respectfully disagree.
3. For every response, state the action taken and the exact manuscript location, or explain why no change was made.
4. If new analysis is requested, assess validity, time, data access, and whether it changes the claim. Never fabricate a result or imply unrun work is complete.
5. When disagreeing, restate the reviewer’s concern fairly, present evidence, acknowledge residual uncertainty, and narrow the claim if needed.
6. Update the manuscript and response letter together; check page/line references after final formatting.
7. Audit tone for defensiveness, sarcasm, blame, and generic thanks without substance.

## Required output

Point-by-point response letter; change map with page/line anchors; unresolved requests; new-analysis status; and a final consistency check against the revised manuscript.

## Integrity and safety gates

- Never claim a new experiment was run when it was not.
- Never fabricate citations, page numbers, or additional data.
- Do not dismiss a valid criticism with rhetoric.
- Do not hide a genuine limitation merely because a reviewer raised it.
